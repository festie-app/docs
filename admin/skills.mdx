Skills group programmes by the ability they test, such as "Language" or "Athletics". You use them for skill toppers and analytics.

Open **Programme** > **Skills** in the sidebar.

## Who can use it

- You see **Skills** only if your sub-fest plan includes skills.
- You need the **Skills & Criteria** read permission to open the page.
- You need **Skills & Criteria** write permission to add, import, edit or delete skills, change max points, or change programmes. Without it, the page is read-only.

## Find a skill

The **Skills** page shows every skill as a card with its name and description.

1. Type in **Search skills** to filter the list.
2. Click a card to open the skill's page.

## Add skills

1. Click **Add** to create one skill. Enter a name and description, then save. The new skill opens right away.
2. Click **Import** to add many skills from a file.
3. Click **Import from sub-fest** to copy skills from another sub-fest. Each skill's candidate max points (matched by category name), team max points and team max mode come along too. Per-team values are not copied.

## Edit or delete a skill

1. Open the skill.
2. Click **Edit** to change its name or description.
3. Click **Delete** to remove it. The skill is removed from all programmes and its max points are deleted.

## Set a skill's max points

Max points are the most a candidate or team can score in this skill. Skill toppers ranked by percentage use them. See [How skill topper percentages work](/admin/toppers#how-skill-topper-percentages-work).

- **Candidate max points** are set per category.
- **Team max points** are set once for the whole skill. They are not split by category.

1. Open the skill.
2. Click **Set max points** at the top. If max points are already set, the button says **Edit max points**. The page "*skill name* · Max points" opens.
3. Under **Candidate max points**, enter a max for each category. Use 0 or more. Decimals are fine. Leave a box empty if you don't want to set it.
4. Under **Team max points**, pick how teams get their max:
   - **Same for all teams**: one max for every team.
   - **Per team**: each team can have its own max.
5. Enter the team max points. See the next sections for each option.
6. Click **Save**. You go back to the skill's page.

Click **Cancel** to go back without saving.

If you only have read permission, the button says **Max points**. You can see the values but not change them.

<Tip>
  Points from common-category programmes count toward the candidate's own category. Include them when you set that category's candidate max.
</Tip>

### Same for all teams

Enter one value in **Team max points**. Every team uses it.

### Per team

You see a **Default** box and a list of every team.

1. In **Default**, enter the value for teams without their own value. If you leave **Default** blank, it counts as 0.
2. Enter a max in a team's box to give that team its own value. Leave it blank to use the default.
3. To give every team the same value, type it in **Fill all** and click **Apply to all**.
4. To clear every team's own value, click **Reset all**. All teams then use the default.

You can copy a column of numbers from a spreadsheet and paste it into a team box. The values fill that team and the teams below it, in order. Press Enter or the arrow keys to move between boxes.

If you switch back to **Same for all teams**, the per-team values are kept but not used.

<Note>
  If you sync **Categories (skills, custom)** to other sub-fests, the candidate max points, the team max points and the team max mode are copied to them too. **Import from sub-fest** copies them the same way. Per-team values are not copied, because teams are different in each sub-fest.
</Note>

## Import possible points for many skills

Use this to set the candidate and team max points of many skills at once, including per-team values.

**Who can do it:** you need **Skills & Criteria** write permission. On desktop, **Import possible points** can be inside the **...** menu at the top of the page.

1. Open **Programme** > **Skills**.
2. Click **Import possible points**.
3. Download a file to start from:
   - **Sample Excel** gives you an example with the right columns and layout. It shows the first few teams as columns.
   - **Current possible points** gives you the values that are set now. It has one row per skill with the team values, and one row per category that has a candidate max.
4. Fill in the file and save it as CSV or XLSX. It can have up to 2000 rows.
5. Upload the file.
6. Check the preview. Each row shows **Ready** or an error. Rows with errors are skipped.
7. Click **Save (n)**, where n is the number of rows that will be saved.
8. On the result screen, see how many rows were **Uploaded**, **Saved** and **Failed**, with the reason for each failure. Then go back to the skills or import another file.

### Columns

| Column | What to enter |
| --- | --- |
| **Skill** | The skill name. |
| **Category** | The category name. Leave it blank on the row with the skill's team values. |
| **Candidate Max Points** | The most a candidate in this category can score in this skill. |
| **Team Max Points** | The team max for the whole skill. With **Per team**, this is the default. |
| **Team Max Points Mode** | **Uniform** (same for all teams) or **Per team**. |
| One column per team | The team's own max for the whole skill. Use the team name as the column header. |

### How to fill the rows

- **Candidate max:** use one row per skill and category. Fill in **Category** and **Candidate Max Points**. A blank **Candidate Max Points** clears that category's value.
- **Team max:** team values belong to the whole skill. Put **Team Max Points**, **Team Max Points Mode** and the team columns on a row with **Category** left blank.
- Leave a team cell blank to keep that team's current value.
- Rows of the same skill must not give different team values or modes. That is an error.
- Team values with mode **Uniform** are an error.
- Only the skills and categories in your file change. Everything else stays as it is.
- Every column that is not one of the columns above must be a team name. Other columns stop the import.

<Note>
  If you sync **Categories (skills, custom)** to other sub-fests, imported candidate max points, team max points and modes are copied to them too. Per-team values are not.
</Note>

## Add or remove programmes

The **Programmes** table on the skill's page lists the programmes tagged with this skill.

1. Click **Add programme**, pick the programmes, and click **Add**.
2. To add many at once by code, click **Add Bulk**. Enter programme codes, one per line or separated by commas, and click **Add Bulk**.
3. To remove programmes, select their rows and click **Remove from skill**.

You can also tag a programme with skills from the programme's own settings. See [Programmes](/admin/programmes).

### Change skills after results

You can add or remove programmes at any result status, even after results are checked or published. Results and points don't change.

Toppers with a **Skill** dimension get a **Needs regeneration** badge. Click **Regenerate** on them to update the standings. See [Toppers](/admin/toppers).
