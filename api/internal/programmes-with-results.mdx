---
title: "Programmes with results"
description: "Read every programme of your festival together with its results in one call with the Internal API."
---

Use this endpoint to get every programme of every subfest of your festival, each with its results, in one call. The maximum points and the teams are listed once per subfest, so the response stays small. You need a key with internal access. See [Authentication](/api/internal/authentication).

This endpoint is read only. It does not change scores and it does not release results.

<Warning>
  **Unpublished results are included.** Results that are not published yet are returned too. Use `isPublished` to tell them apart. Do not show unpublished results to the public.
</Warning>

<Warning>
  **The response can be large.** This endpoint has no pagination and no limit. The server reads the results in chunks, but a big festival can still take a while. Set a client timeout of at least 120 seconds. Call it from your backend server and do not call it often. The rate limit applies.
</Warning>

---

## List programmes with results

Returns all programmes of the festival of your key, ordered by subfest name and then by programme code.

```http
GET /internal-api/v1/programmes-results
```

### Query parameters

All parameters are optional.

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `subFestId` | `UUID` | Return the programmes of this subfest only. Get the ID from [Festival and subfests](/api/internal/festival-and-subfests). |
| `statuses` | `string` | Return only programmes with these result statuses. Send a comma separated list, or repeat the parameter. Values: `DRAFT`, `EVALUATED`, `RESULTS_GENERATED`, `CHECKED_TO_PUBLISH`, `CHECKED_TO_UNPUBLISH`, `RESULTS_PUBLISHED`. |

### Response fields

The response is an object with two arrays: `subFests` and `data`.

```json
{ "subFests": [], "data": [] }
```

- `subFests` has one item per subfest that has programmes in the response. It holds the categories, the maximum points, the teams and the skills.
- `data` has one item per programme, with its results.

Maximum points and teams are the same for every programme of a subfest. We list them once in `subFests` and not inside every result. This keeps the response small, even for a big festival. Programmes and results only carry IDs and names that point into `subFests`.

#### How to read max points

1. Take the `subFestId` of the programme and find that subfest in `subFests`.
2. In that subfest, find the category with the same `id` as the `category.id` of the result.
3. The `candidateMaxPoints` and `teamMaxPoints` of that category are the maximum points of the category.
4. For the maximum points of the team, look in the `participatingTeams` of that category. Find the team by `teamId`, which is the `team.id` of the result.

#### How to read skill max points

The skills of the programme are in the `skills` of the programme.

- **Candidate maximum:** the candidate maximum is set per category. In the subfest, find the category of the result, then find the skill by `skillId` in the `skills` of that category. Use its `candidateMaxPoints`.
- **Team maximum:** the team maximum is set once per skill, not per category. In the subfest, find the skill by `id` in `skills`. If its `teamMaxPointsMode` is `UNIFORM`, use its `teamMaxPoints`. If it is `PER_TEAM`, find the team by `teamId` in the `teams` of that skill.

A maximum that is not set is `null`.

#### Subfest fields

Each item of `subFests` is a subfest.

| Field | Description |
| :--- | :--- |
| `id` | The subfest ID. |
| `name` | The subfest name. |
| `categories` | The categories of the subfest. See [Category fields](#category-fields). |
| `teams` | The teams of the subfest. See [Team fields](#team-fields). |
| `skills` | The skills of the subfest. See [Skill fields](#skill-fields). |

#### Category fields

| Field | Description |
| :--- | :--- |
| `id` | The category ID. |
| `name` | The category name. |
| `type` | `SINGLE` or `COMMON`. |
| `displayOrder` | The order of the category in the subfest. |
| `candidateMaxPoints` | The maximum points for a candidate in this category, or `null`. |
| `teamMaxPoints` | The maximum points for a team in this category, or `null`. |
| `teamMaxPointsMode` | `UNIFORM` or `PER_TEAM`. With `PER_TEAM`, each team can have its own maximum. |
| `skills` | The candidate maximum points of each skill in this category. See [Category skill fields](#category-skill-fields). |
| `participatingTeams` | The teams that take part in this category. Each item has `teamId` and `teamMaxPoints`. In `PER_TEAM` mode this is the own maximum of the team if it is set. Otherwise it is the `teamMaxPoints` of the category. |

<Note>
  The team maximum points ignore the subfest setting that sends common programme points to the common category. They are always the values of the category of the entry.
</Note>

#### Category skill fields

Each item of `skills` in a category is one skill's candidate maximum in that category. The team maximum of a skill is in the subfest `skills`. See [Skill fields](#skill-fields).

| Field | Description |
| :--- | :--- |
| `skillId` | The skill ID. |
| `name` | The skill name. |
| `candidateMaxPoints` | The maximum points for a candidate in this skill and category, or `null`. |

<Note>
  `teamMaxPoints`, `teamMaxPointsMode` and `teams` are no longer returned here. Read them from the subfest `skills`.
</Note>

#### Team fields

| Field | Description |
| :--- | :--- |
| `id` | The team ID. |
| `name` | The team name. |
| `displayName` | The team display name. |
| `colorCode` | The team color code. |
| `participatesInAllCategories` | `true` if the team takes part in all categories of the subfest. |

#### Skill fields

| Field | Description |
| :--- | :--- |
| `id` | The skill ID. |
| `name` | The skill name. |
| `description` | The skill description, or `null`. |
| `teamMaxPoints` | The maximum points for a team in this skill, or `null`. With `PER_TEAM`, this is the default for teams without their own value. |
| `teamMaxPointsMode` | `UNIFORM` or `PER_TEAM`. With `PER_TEAM`, each team can have its own maximum for this skill. |
| `teams` | With `PER_TEAM`, every team of the subfest. Each item has `teamId` and `teamMaxPoints`: the team's own maximum if it is set, otherwise the `teamMaxPoints` of the skill, or `null`. With `UNIFORM`, an empty array. |

#### Programme fields

Each item of `data` is a programme.

| Field | Description |
| :--- | :--- |
| `subFestId` | The subfest ID. Use it to find the subfest in `subFests`. |
| `subFestName` | The subfest name. |
| `programmeId` | The programme ID. |
| `programmeCode` | The programme code. |
| `programmeName` | The programme name. |
| `programmeType` | `INDIVIDUAL`, `GROUP` or `TEAM`. |
| `status` | The result status of the programme. |
| `category` | The category of the programme, or `null`. It has `id` and `name`. |
| `allowedCategories` | The categories that can enter the programme. Each item has `id` and `name`. |
| `skills` | The skills of the programme. Each item has `id` and `name`. |
| `collections` | The collections assigned to the programme. Each item has `id`, `key` and `value`. |
| `results` | The results. See [Result fields](#result-fields). A programme without results has an empty array. |

#### Result fields

Results are ordered by rank, then by total points, highest first. All fields are always returned, except `members`.

| Field | Description |
| :--- | :--- |
| `id` | The result ID. |
| `type` | `INDIVIDUAL` or `GROUP`. |
| `registrationId` | The registration ID of an individual entry, or `null`. |
| `groupRegistrationId` | The registration ID of a group entry, or `null`. |
| `code` | The code letter of the entry, or `null`. |
| `chestNo` | The chest number. `null` for group entries. |
| `name` | The candidate name. For a group entry, the group name. |
| `members` | The members of a group entry. Each item has `chestNo`, `name` and `categoryId`. Not returned for individual entries. |
| `team` | The team of the entry, or `null`. It has `id`, `name` and `displayName`. Find the full team in `teams` of the subfest. |
| `category` | The category of the entry, or `null`. It has `id` and `name`. For an individual entry, this is the category of the candidate. If the candidate has none, it is the category of the programme. For a group entry, it is the category of the programme. |
| `pool` | The subfest name. |
| `position` | The position as a number, or `null`. |
| `rank` | The rank as a number, or `null`. |
| `grade` | The grade, or `null`. |
| `positionPoints` | The points for the position, or `null`. |
| `gradePoints` | The points for the grade, or `null`. |
| `totalPoints` | The total points, or `null`. |
| `candidatePoints` | The points that go to the candidate, or `null`. |
| `teamPoints` | The points that go to the team, or `null`. |
| `totalScore` | The total score, or `null`. |
| `totalOutOf` | The score the total is out of, or `null`. |
| `scorePercentage` | The score as a percentage, or `null`. |
| `isTotalEdited` | `true` if the total score was edited by hand. |
| `originalTotalScore` | The total score before it was edited, or `null`. |
| `isPublished` | `false` if the result is not published yet. |
| `publishedAt` | When the result was published, or `null`. ISO 8601. |
| `createdAt` | When the result was created. ISO 8601. |
| `updatedAt` | When the result was last updated. ISO 8601. |
| `timestamp` | `publishedAt`. If the result is not published, `updatedAt`. ISO 8601. |

All points and scores are strings with decimals, for example `"5.00"`, or `null`.

### Example request

```bash
curl -X GET "https://public-api.festie.app/internal-api/v1/programmes-results" \
  -H "X-API-Key: YOUR_API_KEY" \
  --max-time 120
```

To get one subfest and only published programmes:

```bash
curl -X GET "https://public-api.festie.app/internal-api/v1/programmes-results?subFestId=5a9da3b1-f7a5-4d54-b2a4-6c014d4b411a&statuses=RESULTS_PUBLISHED" \
  -H "X-API-Key: YOUR_API_KEY" \
  --max-time 120
```

### Errors

| Code | Meaning |
| :--- | :--- |
| `400` | A query parameter is invalid. |
| `401` | The key is missing, invalid or expired. |
| `403` | The key does not have internal access. |
| `429` | You went over the rate limit. |
