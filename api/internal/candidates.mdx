---
title: "Candidates"
description: "Read the candidates of a subfest, including drafts and unpublished data, with the Internal API."
---

Use these endpoints to read the candidates of a subfest. You need a key with internal access. See [Authentication](/api/internal/authentication).

These endpoints include drafts and unpublished data.

<Warning>
  **Candidate responses include personal details.** They include email, phone numbers and date of birth. Store your key securely and keep this data on your backend server.
</Warning>

In every path, `{subFestId}` is the subfest ID. Get it from `GET /internal-api/v1/subfests`. See [Festival and subfests](/api/internal/festival-and-subfests).

## Filters and sorting

List filters accept comma-separated values or repeated parameters. For example, `?search=a,b` works the same as `?search=a&search=b`. Boolean filters use `true` or `false`.

---

## List candidates

Returns the candidates of a subfest.

```http
GET /internal-api/v1/subfests/{subFestId}/candidates
```

### Query parameters

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `page` | `integer` | `1` | The page number. |
| `limit` | `integer` | `50` | Records per page. The maximum is `200`. |
| `search` | `string` | — | Search by name, chest number or admission number. |
| `categoryIds` | `UUID` | — | Show only candidates in these categories. |
| `includeUnassignedCategory` | `boolean` | — | Also show candidates with no category. |
| `teamIds` | `UUID` | — | Show only candidates in these teams. |
| `includeUnassignedTeam` | `boolean` | — | Also show candidates with no team. |
| `sectionIds` | `UUID` | — | Show only candidates in these sections. |
| `gender` | `string` | — | Show only this gender: `MALE`, `FEMALE` or `OTHER`. |
| `chestNoPattern` | `string` | — | Show candidates whose chest number contains this text. Not case sensitive. |
| `admNoPattern` | `string` | — | Show candidates whose admission number contains this text. Not case sensitive. |
| `hasAvatar` | `boolean` | — | `true` shows candidates with an avatar. `false` shows candidates without. |
| `hasRegistration` | `boolean` | — | `true` shows candidates with a registration. `false` shows candidates without. |
| `sortBy` | `string` | `chestNo` | Sort field: `chestNo`, `name`, `email`, `admNo`, `teamName`, `categoryName` or `createdAt`. |
| `sortOrder` | `string` | `asc` | Sort direction: `asc` or `desc`. |

### Candidate fields

| Field | Description |
| :--- | :--- |
| `id` | The subfest candidate ID. |
| `subFestId` | The ID of the subfest. |
| `candidateId` | The ID of the candidate profile. |
| `categoryId` | The ID of the category, or `null`. |
| `teamId` | The ID of the team, or `null`. |
| `isActive` | `true` if the candidate is active. |
| `createdAt` | When the record was created. |
| `updatedAt` | When the record was last updated. |
| `candidate` | The candidate profile. See the table below. |
| `category` | The category, with `id` and `name`. `null` if there is none. |
| `team` | The team, with `id`, `name`, `displayName`, `colorCode` and `logoUrl`. `null` if there is none. |
| `sections` | The sections of the candidate. Each section has `id`, `key` and `value`. |

### Candidate profile fields

| Field | Description |
| :--- | :--- |
| `id` | The candidate profile ID. |
| `festivalId` | The festival ID. |
| `chestNo` | The chest number. |
| `name` | The candidate name. |
| `email` | The candidate email. |
| `dob` | The date of birth. |
| `whatsappNumber` | The WhatsApp number. |
| `parentWhatsappNumber` | The parent's WhatsApp number. |
| `avatar` | The full URL of the avatar image, or `null`. |
| `avatarFileId` | The avatar file ID. |
| `gender` | The gender. |
| `admNo` | The admission number. |
| `additionalInfo` | Extra information about the candidate. |
| `createdAt` | When the profile was created. |
| `updatedAt` | When the profile was last updated. |

### Example request

```bash
curl -X GET "https://public-api.festie.app/internal-api/v1/subfests/5a9da3b1-f7a5-4d54-b2a4-6c014d4b411a/candidates?teamIds=3f2c8a14-6b7d-4e19-9c50-1a2b3c4d5e6f&sortBy=name" \
  -H "X-API-Key: YOUR_API_KEY"
```

## Get a candidate

Returns one candidate of a subfest.

```http
GET /internal-api/v1/subfests/{subFestId}/candidates/{candidate}
```

### Path parameters

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `subFestId` | `UUID` | The subfest ID. |
| `candidate` | `string` | The subfest candidate ID or the chest number. |

### Response fields

The response has all the [candidate fields](#candidate-fields) and this extra field:

| Field | Description |
| :--- | :--- |
| `hasRegistrations` | `true` if the candidate is registered in any programme. |

<Note>
  For programmes, results, points and gallery images, use [Get a candidate profile](#get-a-candidate-profile).
</Note>

### Example request

```bash
curl -X GET "https://public-api.festie.app/internal-api/v1/subfests/5a9da3b1-f7a5-4d54-b2a4-6c014d4b411a/candidates/101" \
```

## Get a candidate profile

Returns the full profile of one candidate: the candidate details, programmes, points and gallery images. This endpoint has no pagination.

```http
GET /internal-api/v1/subfests/{subFestId}/candidates/{chestNo}/profile
```

<Warning>
  **Unpublished results are included.** Programme results that are not published yet are returned too. Use `isPublished` to tell them apart. Do not show unpublished results to the public.
</Warning>

<Warning>
  **The profile includes personal details.** It includes email, phone numbers and date of birth. Store your key securely and keep this data on your backend server.
</Warning>

### Path parameters

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `subFestId` | `UUID` | The subfest ID. |
| `chestNo` | `string` | The chest number of the candidate. Not case sensitive. |

### Response fields

| Field | Description |
| :--- | :--- |
| `candidate` | The candidate. It has the same fields as in the other candidate endpoints. See [Candidate fields](#candidate-fields) and [Candidate profile fields](#candidate-profile-fields). |
| `programs` | The programmes the candidate is registered in, newest registration first. See [Programme fields](#programme-fields). |
| `pointSummary` | The points of the candidate. `null` if the candidate has no points yet. See [Point summary fields](#point-summary-fields). |
| `pointAdjustments` | The latest 100 point adjustments that are approved or rejected. Pending adjustments are not included. See [Point adjustment fields](#point-adjustment-fields). |
| `galleryImages` | Up to 60 gallery images of the candidate. See [Gallery image fields](#gallery-image-fields). |

#### Programme fields

| Field | Description |
| :--- | :--- |
| `id` | The registration ID. |
| `subFestProgramId` | The subfest programme ID. |
| `programName` | The programme name. |
| `programCode` | The programme code. |
| `programType` | The programme type: `INDIVIDUAL`, `GROUP` or `TEAM`. |
| `categoryName` | The category name. |
| `registrationId` | The registration ID. |
| `registrationType` | `Single` or `Group`. |
| `topic` | The topic of the entry. |
| `checkedIn` | `true` if the candidate is checked in. |
| `registeredAt` | When the candidate was registered. |
| `result` | The result of the entry, or `null` if there is none. See the table below. |
| `programStatus` | The result status of the programme. |
| `groupName` | The group name. Group entries only. |
| `groupMembers` | The members of the group. Group entries only. Each member has `subFestCandidateId` and `name`. |

The `result` object has these fields:

| Field | Description |
| :--- | :--- |
| `id` | The result ID. |
| `position` | The position. |
| `grade` | The grade. |
| `totalPoints` | The total points. |
| `isPublished` | `false` if the result is not published yet. |

#### Point summary fields

| Field | Description |
| :--- | :--- |
| `totalPoints` | The total points. |
| `publishedPoints` | The points from published results. |
| `totalPointAdjustments` | The total of the point adjustments. |
| `totalPrograms` | The number of programmes. |
| `publishedPrograms` | The number of programmes with published results. |
| `percentage` | The percentage. |

#### Point adjustment fields

| Field | Description |
| :--- | :--- |
| `id` | The adjustment ID. |
| `type` | The type of adjustment: `BONUS` or `NEGATIVE`. |
| `points` | The points added or removed. |
| `reason` | The reason. |
| `remarks` | Extra remarks. |
| `revokedAt` | When the adjustment was revoked, or `null`. |
| `createdAt` | When the adjustment was created. |

#### Gallery image fields

| Field | Description |
| :--- | :--- |
| `id` | The image ID. |
| `albumId` | The album ID. |
| `title` | The image title. |
| `description` | The image description. |
| `imageUrl` | The URL of the image. |
| `thumbnailUrl` | The URL of the thumbnail. |
| `orderIndex` | The position of the image in the album. |
| `createdAt` | When the image was added. |

### Example request

```bash
curl -X GET "https://public-api.festie.app/internal-api/v1/subfests/5a9da3b1-f7a5-4d54-b2a4-6c014d4b411a/candidates/101/profile" \

```
