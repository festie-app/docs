---

Use these endpoints to read the programmes of a subfest and the registrations of each programme. You need a key with internal access. See [Authentication](/api/internal/authentication).

These endpoints include drafts and unpublished data.

<Warning>
  **Registration responses include personal details.** The person who marked attendance is returned with their email. Store your key securely and keep this data on your backend server.
</Warning>

In every path, `{subFestId}` is the subfest ID. Get it from `GET /internal-api/v1/subfests`. See [Festival and subfests](/api/internal/festival-and-subfests).

## Filters and sorting

List filters accept comma-separated values or repeated parameters. For example, `?statuses=DRAFT,EVALUATED` works the same as `?statuses=DRAFT&statuses=EVALUATED`. Boolean filters use `true` or `false`.

<Note>
  **Not included yet.** These are not available in the REST API yet:

  - The subfest's inherited (effective) judging settings.
  - The effective substitution rules and substitution window times.
  - The filters `scheduleStatus`, `templateGeneration` and `queueOrder`.
</Note>

## List programmes

Returns the programmes of a subfest.

```http
GET /internal-api/v1/subfests/{subFestId}/programmes
```

### Query parameters

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `page` | `integer` | `1` | The page number. |
| `limit` | `integer` | `50` | Records per page. The maximum is `200`. |
| `search` | `string` | — | Search by programme name, code, concept note or category name. |
| `categoryIds` | `UUID` | — | Show only programmes in these categories. |
| `venues` | `UUID` | — | Show only programmes scheduled at these venues. Use venue IDs. |
| `statuses` | `string` | — | Show only programmes with these result statuses: `DRAFT`, `EVALUATED`, `RESULTS_GENERATED`, `CHECKED_TO_PUBLISH`, `CHECKED_TO_UNPUBLISH` or `RESULTS_PUBLISHED`. |
| `programType` | `string` | — | Show only this programme type: `INDIVIDUAL`, `GROUP` or `TEAM`. |
| `programCodePattern` | `string` | — | Show programmes whose code contains this text. Not case sensitive. |
| `collectionIds` | `UUID` | — | Show only programmes in these collections. |
| `judges` | `UUID` | — | Show only programmes with these judges. Use judge IDs. A judge of any round counts. |
| `hasSchedule` | `boolean` | — | `true` shows programmes with a schedule. `false` shows programmes without. |
| `hasResults` | `boolean` | — | `true` shows programmes with results. `false` shows programmes without. |
| `hasJudges` | `boolean` | — | `true` shows programmes with judges. `false` shows programmes without. |
| `hasRegistrations` | `boolean` | — | `true` shows programmes with registrations. `false` shows programmes without. |
| `candidateRegistrationOpen` | `boolean` | — | `true` shows programmes where candidate registration is open. `false` shows programmes where it is not. |
| `topicRegistrationOpen` | `boolean` | — | `true` shows programmes where topic registration is open. `false` shows programmes where it is not. |
| `requiresTopicRegistration` | `boolean` | — | `true` shows programmes that need a topic. `false` shows programmes that do not. |
| `sortBy` | `string` | category order, then programme code | Sort field: `programCode`, `programName`, `categoryName`, `createdAt`, `updatedAt`, `publishedAt` or `resultStatus`. |
| `sortOrder` | `string` | `asc` | Sort direction: `asc` or `desc`. |

### Programme fields

| Field | Description |
| :--- | :--- |
| `id` | The subfest programme ID. |
| `subFestId` | The ID of the subfest. |
| `programId` | The ID of the programme. |
| `categoryId` | The ID of the category, or `null`. |
| `publishedAt` | When the results were published, or `null`. |
| `resultStatus` | The result status: `DRAFT`, `EVALUATED`, `RESULTS_GENERATED`, `CHECKED_TO_PUBLISH`, `CHECKED_TO_UNPUBLISH` or `RESULTS_PUBLISHED`. |
| `createdAt` | When the record was created. |
| `updatedAt` | When the record was last updated. |
| `program` | The programme. It has `id`, `name`, `code`, `conceptNote` and `programType` (`INDIVIDUAL`, `GROUP` or `TEAM`). |
| `category` | The category, with `id` and `name`. `null` if there is none. |
| `programCollections` | The collections of the programme. Each item has `id` and `collection` (`id`, `key` and `value`). |
| `programSkills` | The skills of the programme. Each item has `id` and `skill` (`id` and `name`). |
| `schedule` | The first schedule slot, or `null`. See [Schedule fields](#schedule-fields). |
| `schedules` | All schedule slots of the programme. |
| `registrationCount` | The number of registrations. Single registrations for `INDIVIDUAL` programmes. Group registrations for `GROUP` and `TEAM` programmes. |
| `programRegistrationCount` | The number of single registrations. |
| `groupRegistrationCount` | The number of group registrations. |
| `scheduleCount` | The number of schedule slots. |
| `judgeCount` | The number of judges. |
| `resultCount` | The number of results. |
| `hasSchedule` | `true` if the programme has a schedule. |
| `hasJudges` | `true` if the programme has judges. |
| `hasResults` | `true` if the programme has results. |
| `hasRegistrations` | `true` if the programme has registrations. |

| `maxParticipantsInGroup` | The maximum number of participants in a group. |

**Judging and results**

| Field | Description |
| :--- | :--- |
| `judgmentType` | The judgment type of the programme. |
| `customJudgmentSettings` | The programme's own judging settings. |
| `pointPercentages` | The point percentages. |
| `enableGrading` | `true` if grading is on. |
| `enablePosition` | `true` if positions are on. |
| `gradeCriteriaId` | The ID of the grade criteria. |
| `positionCriteriaId` | The ID of the position criteria. |
| `judgementCriteriaId` | The ID of the judgement criteria. |

**Registration**

| Field | Description |
| :--- | :--- |
| `candidateRegistrationMode` | `CLOSED`, `OPEN` or `SCHEDULED`. |
| `candidateRegistrationStatus` | `CLOSED`, `OPEN` or `SCHEDULED`. |
| `candidateRegistrationStart` and `candidateRegistrationEnd` | The start and end dates of candidate registration. |
| `candidateRegistrationOpen` | `true` if candidate registration is open. |

**Timing and rounds**

| Field | Description |
| :--- | :--- |
| `roundType` | `NONE`, `ELIMINATION` or `CUMULATIVE`. |
| `durationType` | The duration type. |

| `durationMinutes` | The duration in minutes. |
| `warningMinutes` | The warning time, minutes part. |
| `warningSeconds` | The warning time, seconds part. |
| `rounds` | The rounds of the programme. See [Round fields](#round-fields). |

A few extra tracking fields of the programme are also included.

#### Schedule fields

#### Round fields

| Field | Description |
| :--- | :--- |
| `id` | The round ID. |

### Example request

```bash
curl -X GET "https://public-api.festie.app/internal-api/v1/subfests/5a9da3b1-f7a5-4d54-b2a4-6c014d4b411a/programmes?statuses=DRAFT,EVALUATED&hasSchedule=true&sortBy=programCode" \
  -H "X-API-Key: YOUR_API_KEY"
```

## Get a programme

Returns one programme of a subfest.

```http
GET /internal-api/v1/subfests/{subFestId}/programmes/{programme}
```

### Path parameters

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `subFestId` | `UUID` | The subfest ID. |
| `programme` | `string` | The subfest programme ID or the programme code. |

### Response fields

The response is one programme with all the [programme fields](#programme-fields).

### Example request

```bash
curl -X GET "https://public-api.festie.app/internal-api/v1/subfests/5a9da3b1-f7a5-4d54-b2a4-6c014d4b411a/programmes/J-101" \
  -H "X-API-Key: YOUR_API_KEY"
```

### Example response

The response has the same shape as one item in the list. See the example above.

### Errors

| Code | Meaning |
| :--- | :--- |
| `400` | The subfest ID or programme is invalid. |
| `401` | The key is missing, invalid or expired. |
| `403` | The key does not have internal access. |
| `404` | The subfest is not in your festival, or the programme does not exist. |
| `429` | You went over the rate limit. |

## List programme registrations

Returns all registrations of one programme. This endpoint has no pagination. It returns every registration.

```http
GET /internal-api/v1/subfests/{subFestId}/programmes/{programme}/registrations
```

### Path parameters

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `subFestId` | `UUID` | The subfest ID. |
| `programme` | `string` | The subfest programme ID or the programme code. |

### Response fields

| Field | Description |
| :--- | :--- |
| `programType` | The programme type: `INDIVIDUAL`, `GROUP` or `TEAM`. |
| `eligibleTeamCount` | The number of teams that can take part. If no teams are restricted, this is the number of all teams in the subfest. |
| `singleRegistrations` | The single registrations. See [Single registration fields](#single-registration-fields). |
| `groupRegistrations` | The group registrations. See [Group registration fields](#group-registration-fields). |

<Warning>
  **Attendance marker details are personal data.** `attendanceMarker` includes the email of the person who marked attendance. Handle it with care.
</Warning>

#### Single registration fields

| Field | Description |
| :--- | :--- |
| `id` | The registration ID. |
| `subFestProgramId` | The subfest programme ID. |
| `subFestCandidateId` | The subfest candidate ID. |
| `teamId` | The team ID. |
| `topic` | The topic. |
| `topicDetails` | More details about the topic. |
| `topicStatus` | The topic approval status. |
| `topicRemarks` | Remarks about the topic. |
| `topicSubmitted` | `true` if the topic was submitted. |
| `topicApprovedAt` | When the topic was approved. |
| `checkedIn` | `true` if the candidate checked in. |
| `checkedInAt` | When the candidate checked in. |
| `checkedInBy` | The ID of the person who checked the candidate in. |
| `attendanceMarker` | The person who marked attendance, with `id`, `fullName` and `email`. `null` if there is none. |
| `codeLetter` | The code letter. |
| `registeredAt` | When the candidate registered. |
| `subFestCandidate` | The candidate. See [Registered candidate fields](#registered-candidate-fields). |
| `team` | The team, with `id`, `name`, `displayName`, `colorCode` and `logoUrl`. `null` if there is none. |

#### Group registration fields

| Field | Description |
| :--- | :--- |
| `id` | The registration ID. |
| `subFestProgramId` | The subfest programme ID. |
| `teamId` | The team ID. |
| `groupName` | The group name. |
| `topic` | The topic. |
| `topicDetails` | More details about the topic. |
| `topicStatus` | The topic approval status. |
| `topicRemarks` | Remarks about the topic. |
| `topicApprovedAt` | When the topic was approved. |
| `topicLastUpdated` | When the topic was last updated. |
| `checkedIn` | `true` if the group checked in. |
| `checkedInAt` | When the group checked in. |
| `checkedInBy` | The ID of the person who checked the group in. |
| `attendanceMarker` | The person who marked attendance, with `id`, `fullName` and `email`. `null` if there is none. |
| `codeLetter` | The code letter. |
| `createdAt` | When the registration was created. |
| `team` | The team, with `id`, `name`, `displayName`, `colorCode` and `logoUrl`. `null` if there is none. |
| `members` | The members of the group. Each member has `id`, `checkedIn`, `checkedInAt`, `subFestCandidateId` and `subFestCandidate`. |

#### Registered candidate fields

| Field | Description |
| :--- | :--- |
| `id` | The subfest candidate ID. |
| `teamId` | The team ID. |
| `categoryId` | The category ID. |
| `category` | The category, with `id` and `name`. |
| `candidate` | The candidate, with `id`, `name`, `chestNo`, `admNo`, `avatar` and `gender`. |
| `sections` | The sections of the candidate. Each section has `id`, `key` and `value`. |

```bash
  -H "X-API-Key: YOUR_API_KEY"
```
