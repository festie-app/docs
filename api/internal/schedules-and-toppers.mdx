---
title: "Schedules and toppers"
description: "Read the schedule and the topper lists of a subfest, including unpublished data, with the Internal API."
---

Use these endpoints to read the schedule of a subfest and its topper lists. You need a key with internal access. See [Authentication](/api/internal/authentication).

These endpoints are read only. They include drafts and unpublished data, such as schedule slots that are not published yet.

In every path, `{subFestId}` is the subfest ID. Get it from `GET /internal-api/v1/subfests`. See [Festival and subfests](/api/internal/festival-and-subfests).

---

## List schedules

Returns the schedule slots of a subfest. This is the working schedule, so it includes slots that are not published yet.

```http
GET /internal-api/v1/subfests/{subFestId}/schedules
```

### Query parameters

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `page` | `integer` | `1` | The page number. |
| `limit` | `integer` | `50` | Records per page. The maximum is `200`. |
| `subFestProgramId` | `UUID` | — | Show only slots of this subfest programme. |
| `subFestProgramIds` | `UUID` | — | Show only slots of these subfest programmes. Use comma-separated IDs. |
| `venueId` | `UUID` | — | Show only slots at this venue. |
| `scheduledAtFrom` | `string` | — | Show only slots from this date and time. Use an ISO date-time. |
| `scheduledAtTo` | `string` | — | Show only slots up to this date and time. Use an ISO date-time. |
| `sortOrder` | `string` | `asc` | Sorts by scheduled time: `asc` or `desc`. |

### Schedule fields

| Field | Description |
| :--- | :--- |
| `id` | The schedule slot ID. |
| `subFestId` | The ID of the subfest. |
| `subFestProgramId` | The subfest programme ID. |
| `scheduledAt` | When the slot starts. |
| `durationMinutes` | The length of the slot in minutes. |
| `venueId` | The ID of the venue, or `null`. |
| `roundId` | The ID of the round, or `null`. |
| `roundName` | The name of the round, or `null`. |
| `createdAt` | When the record was created. |
| `updatedAt` | When the record was last updated. |
| `venue` | The venue, with `id` and `name`. `null` if there is none. |
| `subFestProgram` | The programme, with `id`, `name`, `code` and `categoryName`. |
| `programmeConflictCount` | The number of unresolved clashes that involve this programme. |
| `unresolvedConflictCount` | The number of unresolved clashes in the whole subfest. |

### Example request

```bash
curl -X GET "https://api.festie.app/internal-api/v1/subfests/5a9da3b1-f7a5-4d54-b2a4-6c014d4b411a/schedules?venueId=c4d5e6f7-a8b9-4c0d-8e1f-2a3b4c5d6e7f&sortOrder=asc" \
  -H "X-API-Key: YOUR_API_KEY"
```

## List topper lists

Returns the topper lists of a subfest. A topper list is also called a topper placeholder. This endpoint has no pagination.

```http
GET /internal-api/v1/subfests/{subFestId}/toppers
```

### Topper list fields

| Field | Description |
| :--- | :--- |
| `id` | The topper list ID. Use it as `{placeholderId}` below. |
| `subFestId` | The ID of the subfest. |
| `label` | The name of the list. |
| `entityType` | What the list ranks. |
| `scopeConfig` | How the list is grouped. |
| `rankingBasis` | What the ranking is based on. |
| `maxPointsOverride` | The highest points override, or `null`. |
| `displayTopN` | How many entries to show. |
| `allowedTies` | Whether ties are allowed. |
| `tieBreakerConfig` | How ties are broken. |
| `displayOrder` | The order of the list. |
| `isPublished` | `true` if the list is published. |
| `isDefault` | `true` if this is a default list. |
| `dirty` | `true` if the list needs to be calculated again. |
| `lastComputedAt` | When the list was last calculated, or `null`. |
| `lastResultVersion` | The result version of the last calculation. |
| `createdAt` | When the record was created. |
| `updatedAt` | When the record was last updated. |

### Example request

```bash
curl -X GET "https://api.festie.app/internal-api/v1/subfests/5a9da3b1-f7a5-4d54-b2a4-6c014d4b411a/toppers" \
  -H "X-API-Key: YOUR_API_KEY"
```

## List topper entries

Returns the ranked entries of one topper list. This endpoint has no pagination. Only entries with points above `0` are returned. Hidden entries are included and flagged with `isHidden`.

```http
GET /internal-api/v1/subfests/{subFestId}/toppers/{placeholderId}
```

### Path parameters

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `subFestId` | `UUID` | The subfest ID. |
| `placeholderId` | `UUID` | The topper list ID. Get it from the list above. |

### Response fields

| Field | Description |
| :--- | :--- |
| `placeholderId` | The topper list ID. |
| `data` | The ranked entries. See [Entry fields](#entry-fields). |

#### Entry fields

| Field | Description |
| :--- | :--- |
| `id` | The entry ID. |
| `placeholderId` | The topper list ID. |
| `rank` | The rank. |
| `subFestCandidateId` | The subfest candidate ID. |
| `teamId` | The team ID. |
| `sectionId` | The section ID. |
| `candidateName` | The candidate name. |
| `candidateChestNo` | The candidate chest number. |
| `candidateAvatar` | The candidate avatar URL, or `null`. |
| `teamName` | The team name. |
| `teamColor` | The team colour. |
| `categoryName` | The category name. |
| `candidateSectionKeys` | The section keys of the candidate. |
| `candidateSectionValues` | The section values of the candidate. |
| `candidateSectionLabels` | The section labels of the candidate. |
| `groupCategoryId` | The category ID of a group entry. |
| `groupTeamId` | The team ID of a group entry. |
| `groupSectionId` | The section ID of a group entry. |
| `groupCollectionId` | The collection ID of a group entry. |
| `groupLabel` | The label of a group entry. |
| `points` | The points. |
| `rawPoints` | The points before any change. |
| `percentage` | The percentage. |
| `programCount` | The number of programmes counted. |
| `entrySource` | The entry source: calculated automatically or added by hand. |
| `isLocked` | `true` if the entry is locked. |
| `manualNote` | A note added by hand, or `null`. |
| `manualAt` | When the entry was changed by hand, or `null`. |
| `isHidden` | `true` if the entry is hidden. |
| `hiddenAt` | When the entry was hidden, or `null`. |

### Example request

```bash
curl -X GET "https://api.festie.app/internal-api/v1/subfests/5a9da3b1-f7a5-4d54-b2a4-6c014d4b411a/toppers/7c8d9e0f-1a2b-4c3d-8e4f-5a6b7c8d9e0f" \
```
